## 트랙패드 제스처

트랙패드 탭에서 새 규칙을 만들고 기본 제스처를 선택하거나 **사용자 제스처 녹화**를 엽니다.

한 번에 선택된 트랙패드 한 대에서 입력을 받습니다. 사용 가능한 외장 Magic Trackpad가 있으면 우선 사용하고, 없으면 내장 트랙패드를 사용합니다. 연결 변경 후 입력 확인 안내가 나오면 사용할 트랙패드에 두 손가락을 잠시 올렸다가 모두 떼세요. 이 확인 중에는 연결된 동작이 실행되지 않습니다.

접촉·탭·이동은 기기의 실제 입력으로 확인합니다. 압력 기반 제스처는 압력 데이터를 제공하는 기기에서만 사용할 수 있으며, Force Touch가 없는 구형 트랙패드는 해당 기능을 사용할 수 없습니다. 일반 클릭과 세게 누르기는 다른 입력입니다.

녹화할 때는 `⌘ + ⇧`를 누른 채 원하는 동작을 합니다. 손가락을 모두 뗀 다음 키를 놓으면 분석합니다. 이름을 정해 **이 규칙에 저장**한 뒤 녹화·테스트를 마칩니다.

여러 번 탭하거나 탭 다음에 스와이프하는 순서를 녹화할 수 있습니다. 전체 길이는 최대 5초이며, 최대 32단계와 동시 접촉 5개를 다룹니다. 센서의 접촉 순서·위치·경로를 기록하며 검지·중지 같은 손가락 이름은 구분하지 않습니다.

### 빠르거나 느린 동작에 맞추기

먼저 **녹화 기준 / 여유 조금 / 여유 많이** 중 하나를 선택하세요. 두 시간 설정을 함께 바꾸는 빠른 설정이며, 이후 각각 조절할 수 있습니다.

| 빠른 설정 | 두 항목에 추가되는 여유 |
| --- | --- |
| 녹화 기준 | +0초 |
| 여유 조금 | +0.3초 |
| 여유 많이 | +1초 |

세부 조절은 **시간 여유 조절**을 펼칩니다.

- **터치 사이 시간 여유:** 손가락을 뗐다 다시 대는 간격이나 다른 손가락을 유지한 상태에서 탭 사이에 쉬는 시간을 더 허용합니다.
- **동작 길이 여유:** 손가락을 대고 있는 시간을 녹화 때보다 짧거나 길게 허용합니다.

두 항목은 각각 0~3초를 추가로 허용하며 0.05초씩 조절할 수 있습니다. 0초는 녹화 기준의 기본 허용 범위입니다. 여유를 늘려도 전체 동작은 5초 안에 마쳐야 합니다.

**저장한 제스처**에서 바꾼 시간 설정은 그 제스처에 연결된 규칙에 함께 적용됩니다.

## 키보드 매크로

- **순서대로 입력:** Q를 눌렀다가 뗀 뒤 W를 누르는 방식입니다. 첫 키에서 손을 뗀 다음 두 번째 키를 누르세요.
- **키 조합:** Shift를 누른 채 1을 누르는 것처럼 보조 키와 일반 키를 함께 누르는 방식입니다.

순서 입력은 **빠르게(0.2초) / 기본(0.4초) / 여유롭게(1초)** 중 하나로 시작할 수 있습니다. 빠른 설정은 기존 시간 값에 바로 적용되며, 세부 값을 바꾸면 사용자 설정으로 표시됩니다.

순서 입력의 **두 키 사이 최대 시간**은 0.01~5초로 조절합니다. 첫 키를 누른 순간부터 다음 키를 누를 때까지의 제한이며, 설정한 시간 안에서는 더 빠르게 입력해도 인식합니다.

입력은 현재 사용 중인 앱에도 전달됩니다. 평소 타이핑과 겹치지 않는 조합을 선택하세요.

### 실행 입력과 출력할 키를 따로 정하기

**입력 설정**은 매크로를 시작하는 키이고, **실행 동작**은 작업 중인 앱에 보낼 키나 문구입니다.

1. 키보드 매크로 탭에서 규칙을 만들고 실행 입력을 정합니다. 예를 들어 **키 조합 → Shift+A**를 지정합니다.
2. **동작 추가 → 문구 타이핑**을 선택하고 `youtube.com`을 입력합니다. 주소를 여는 동작이 아니라 현재 입력 위치에 문구를 타이핑합니다. Enter도 필요하면 다음 동작으로 추가하세요.
3. 앱의 단축키를 보내려면 **동작 추가 → 키·단축키 누르기 → 누를 키 직접 지정**을 선택한 뒤 보낼 키를 누릅니다. 단일 키 `V`, `[`, `]`나 `⌘C`, `⌘⇧S` 같은 조합을 지정할 수 있습니다. 기존 실행 입력은 바뀌지 않습니다.
4. 필요한 동작을 위에서 아래로 배치하고 적용할 앱을 정합니다. 대상 창에서 **동작 테스트**로 확인한 뒤 규칙을 켭니다.

키 지정 중에는 다른 입력 인식을 잠시 멈춥니다. 취소하거나 다른 앱으로 이동하면 키 지정을 종료합니다. 실제 실행은 macOS 키 입력 이벤트를 사용하므로 대상 앱의 단축키 설정과 현재 포커스에 따라 결과가 달라집니다. Photoshop 등의 모든 앱에서 동작을 확인한 것은 아닙니다. 문구 타이핑은 Unicode 문자를 보내며, 앱 도구·명령을 실행하려면 **키·단축키 누르기**를 사용하세요.

## 퀵 메뉴

메인 창 상단의 네 번째 탭 **퀵 메뉴**에서 설정합니다. 설정은 변경할 때 저장됩니다.

1. **메뉴 배치**에서 4·5·8·9분할을 고릅니다.
2. 위치를 클릭하고 **연결 대상**을 정합니다. **일반 동작**은 **동작 변경**으로 동작을 고르고 필요한 항목을 채웁니다. 저장한 키보드 매크로를 선택하면 그 규칙의 동작들을 실행합니다.
3. **표시 이름**은 원하는 이름을 입력하거나 비워 두어 동작 또는 매크로 이름을 사용합니다.
4. **메뉴 미리보기**로 선택 방법을 확인합니다. 미리보기에서 항목을 선택해도 실제 동작은 실행하지 않습니다.
5. **퀵 메뉴 사용**을 켜고 **실행 키**를 고릅니다. Fn / 🌐, Control, Option, Shift, Command를 선택하거나 **다른 키 지정**으로 일반 키를 등록합니다. 처음 설정할 때는 키 사용이 꺼져 있고 Control이 선택되어 있습니다.

| 배치 | 선택할 수 있는 위치 | 가운데에서 키를 놓으면 |
| --- | --- | --- |
| 4분할 | 상·하·좌·우 | 취소 |
| 5분할 | 상·하·좌·우 + 가운데 | 가운데 동작 실행 |
| 8분할 | 상·하·좌·우 + 대각선 | 취소 |
| 9분할 | 8방향 + 가운데 | 가운데 동작 실행 |

배치를 바꿔도 숨겨진 위치의 이름과 동작은 유지됩니다. 예를 들어 9분할에서 4분할로 바꿨다가 돌아오면 대각선과 가운데 설정을 다시 사용할 수 있습니다.

### 매크로 탭의 규칙을 연결하기

**퀵 메뉴 → 위치 선택 → 연결 대상 → 저장한 키보드 매크로**를 선택하세요. 원본 규칙의 활성화된 동작을 순서대로 실행하고, 오류 발생 시 중단/계속 설정도 따릅니다. 원본 이름과 동작을 수정하면 다음 사용에 반영됩니다. 직접 입력한 표시 이름은 그대로 유지됩니다.

원본 규칙과 해당 프리셋을 켜고, 필요한 경우 활성 프리셋으로 선택하세요. 앱별 적용 범위도 메뉴를 열었던 앱에 맞아야 합니다. 삭제되거나 꺼진 규칙, 사용할 수 없는 프리셋, 실행할 동작이 없는 규칙은 실행하지 않으며 안내를 표시합니다. **퀵 메뉴 열기**가 포함된 규칙은 메뉴 안에서 실행할 수 없습니다.

메뉴에서 선택하면 원본의 실행 키를 대신 누르는 것이 아니라 저장된 동작 목록을 실행합니다. 따라서 키보드 매크로를 수정하면 키 입력으로 실행할 때와 메뉴에서 선택할 때 같은 동작 구성을 사용합니다.

### 키로 열기와 규칙으로 열기

- **실행 키:** 작업할 앱에서 키를 누른 채 원하는 위치로 커서를 움직이고 키를 놓습니다. 5·9분할에서는 커서를 움직이지 않고 놓아도 가운데 동작을 실행하므로 설정한 동작을 확인하세요.
- **트랙패드·키보드 규칙:** 규칙의 실행 동작에 **퀵 메뉴 열기**를 추가합니다. 이렇게 연 메뉴는 항목을 클릭해 선택합니다. 이 방식은 전용 실행 키를 켜지 않아도 사용할 수 있습니다.
- **취소:** Esc 또는 다른 앱으로 이동하면 취소합니다. 실행 키를 누른 상태에서 클릭·드래그·스크롤을 시작해도 취소합니다.

선택한 동작은 메뉴를 열었던 앱을 대상으로 하며, 해당 동작의 권한·확인 절차를 따릅니다. 퀵 메뉴 안에 다시 **퀵 메뉴 열기**를 넣는 중첩 구성은 지원하지 않습니다.

### Fn과 실행 키 충돌

퀵 메뉴와 화면 분할에 같은 키를 지정하면 **화면 분할이 우선**합니다. 예를 들어 퀵 메뉴는 Fn, 화면 분할은 Option처럼 다르게 정하세요. 일반 문자 키는 사용 중인 앱에도 입력됩니다.

Fn은 F1 같은 기능 키와 다릅니다. macOS에서 Fn / 🌐를 누르면 이모티콘이나 입력 소스 전환이 함께 실행될 수 있습니다. 원하지 않으면 **시스템 설정 → 키보드 → fn 또는 🌐 키를 누를 때 실행할 동작 → 동작 없음**을 선택하세요. Flicklane은 이 시스템 설정을 자동으로 변경하지 않습니다. [Apple 키보드 설정 안내](https://support.apple.com/ko-kr/guide/mac-help/kbdm162/mac)

## 화면 분할

**화면 분할** 탭에서 기능을 켜고 실행 키를 정합니다. Fn / 🌐와 보조 키, 직접 지정한 키를 사용할 수 있습니다. 배치할 창을 선택한 뒤 실행 키를 누른 채 마우스를 움직이고 키를 놓습니다.

- 중앙: 현재 데스크톱에서 최대화
- 상·하·좌·우: 화면의 절반
- 대각선: 화면의 사분면

클릭·드래그·스크롤을 시작하면 선택이 해제됩니다. 앱별 최소 창 크기에 따라 정확한 분할 크기가 달라질 수 있습니다.

## 규칙 테스트와 관리

**입력 설정 → 실행 동작 → 적용 및 테스트** 순서로 설정합니다. 여러 동작은 위에서 아래로 실행합니다. 각 동작의 더 보기 메뉴에서 순서를 바꾸거나 삭제할 수 있습니다.

**인식만 테스트**는 연결된 동작을 실행하지 않습니다. **동작 테스트**는 3초 뒤 실제 동작을 한 번 실행하므로 사용할 대상 창으로 이동하세요. 규칙 복제·이름 관리·삭제는 활성화 스위치 옆 관리 메뉴에 있습니다.

## 설정, 업데이트와 진단 정보

메인 창 오른쪽 위 톱니바퀴에서 설정을 엽니다.

- **업데이트 확인:** 버튼을 누를 때만 GitHub 릴리스를 조회합니다. 새 버전이 있으면 릴리스 페이지에서 직접 다운로드하세요. 자동 설치는 하지 않습니다.
- **진단 정보 미리보기 → 진단 정보 복사:** 앱 버전, macOS 버전·빌드, CPU 아키텍처, Mac 모델, 언어, 입력 모니터링·손쉬운 사용·화면 기록 권한과 트랙패드 입력 상태를 확인한 뒤 클립보드에 복사합니다. 규칙·입력 기록·파일 경로는 포함하지 않으며 자동 전송하지 않습니다.

업데이트 확인에 실패하면 인터넷 연결을 확인하고 다시 시도하세요. GitHub 요청 한도 안내가 나오면 잠시 뒤 재시도할 수 있습니다. 문의는 [Issues](https://github.com/zamk-DAV/trackpad/issues)에 재현 순서와 함께 남겨주세요.

## 언어와 메뉴 막대

메인 창 오른쪽 위 톱니바퀴 → **언어**에서 시스템 설정 따르기, 한국어, 영어, 일본어, 중국어 간체·번체 중 하나를 선택합니다. 언어 변경은 재실행 후 적용됩니다. 녹화나 테스트 중이라면 작업을 마친 뒤 다시 시작하세요.

상단 메뉴 막대의 Flicklane 아이콘에는 다음 세 항목이 있습니다.

- **♥ 후원:** 기본 브라우저로 [후원 페이지](https://buymeacoffee.com/flicklane)를 엽니다.
- **⚙ 설정:** 앱 메인 창을 엽니다. 이미 열려 있으면 해당 창으로 돌아갑니다.
- **⏻ 종료:** 앱을 종료합니다.

## 동작 취소와 텍스트 입력

영역·창 캡처에서 Esc로 취소하거나 확인창에서 실행을 취소하면, 그 실행에 연결된 나머지 동작도 멈춥니다. 이미 실행한 동작은 되돌리지 않습니다. 오류 후 계속하기 설정과 관계없이 명시적인 취소를 우선합니다.

텍스트 입력은 이모지와 확장 한자가 이벤트 경계에서 잘리지 않도록 처리합니다. 취소는 남은 동작을 멈추는 기능이며, 이미 입력한 텍스트나 완료한 작업을 되돌리는 실행 취소 기능은 아닙니다.

| Fn을 누르면 이모티콘도 열림 | 위의 Fn 설정 안내에서 macOS 키보드 동작을 확인합니다. |
| 메뉴는 열리는데 선택한 동작이 안 됨 | 미리보기인지 확인하고, 동작의 대상 앱·파라미터·권한을 확인합니다. 메뉴가 열린 뒤 다른 앱으로 이동하면 취소됩니다. |
| 연결한 매크로가 실행되지 않음 | 원본 규칙·프리셋의 활성화 상태, 앱 적용 범위와 실행 동작을 확인합니다. 삭제된 규칙은 다시 연결해야 합니다. |
| 캡처 권한을 허용했는데 캡처가 안 됨 | **입력 상태 및 권한 → 화면 기록**을 확인하고 [권한 복구](installation.md#허용했는데-인식되지-않을-때) 절차를 따릅니다. |
| 캡처 취소 후 다음 동작이 실행되지 않음 | 0.1.3부터 적용한 동작입니다. 취소한 실행의 나머지는 중단됩니다. |
| 빠른/느린 순서 입력이 인식되지 않음 | 첫 키를 뗀 뒤 다음 키를 누르는지 확인하고 **두 키 사이 최대 시간**을 조절합니다. |
| 트랙패드가 준비 중으로 남음 | 선택된 트랙패드에 두 손가락을 올렸다가 모두 뗍니다. 권한·기기 연결 상태도 확인합니다. |

해결되지 않으면 [오류 제보](https://github.com/zamk-DAV/trackpad/issues/new?template=bug_report.yml)에 사용 기능과 재현 순서를 적고, 필요한 경우 검토한 진단 정보만 첨부하세요.
