# Flicklane 0.1.1 Beta 1

**빌드 20 · Universal: Apple silicon + Intel · macOS 14 / 15 / 26**

[**다운로드 / Download (.zip)**](https://github.com/zamk-DAV/trackpad/releases/download/v0.1.1-beta.1/Flicklane-0.1.1-20-universal.zip)

## 한국어

### 바뀐 점

- macOS 14·15·26을 호환 대상으로 확장하고 Intel과 Apple silicon 실행 파일을 하나의 앱에 담았습니다.
- 외장 Apple Magic Trackpad의 접촉·클릭 입력을 같은 기기에 연결해 확인합니다. 사용 가능한 외장 기기를 우선 선택하며, 한 번에 한 대만 활성화합니다. Force Touch가 없는 기기에서는 압력 기반 제스처를 사용할 수 없습니다.
- 새 호환 환경과 외장 트랙패드는 두 손가락을 잠시 올렸다가 모두 떼는 입력 확인 후 동작을 활성화합니다. 확인 중에는 연결된 동작이 실행되지 않습니다.
- 키보드 시간 설정에 **빠르게 / 기본 / 여유롭게**, 녹화 제스처에 **녹화 기준 / 여유 조금 / 여유 많이**를 추가했습니다. 세부 시간 값도 계속 조절할 수 있습니다.
- 설정에 현재 버전과 **업데이트 확인**을 추가했습니다. 버튼을 누를 때만 GitHub 릴리스를 조회하며 자동 설치하지 않습니다.
- **진단 정보 미리보기 → 진단 정보 복사**로 제한된 기술 정보만 확인하고 복사할 수 있습니다. 규칙·입력 기록·개인 파일 경로를 포함하거나 자동 전송하지 않습니다.
- 한·영 설치·사용·개인정보 안내를 정리했습니다.

### 설치와 호환성

1. ZIP을 받아 압축을 풉니다.
2. 기존 Flicklane을 종료하고 새 `Flicklane.app`을 응용 프로그램 폴더로 옮깁니다.
3. 앱을 열어 권한 안내와 입력 확인을 완료합니다.

기존 규칙과 녹화 제스처는 같은 저장 위치를 유지합니다. 권한이 허용되어 있는데 감지되지 않으면 시스템 설정에서 이전 Flicklane 권한 항목을 제거하고 응용 프로그램 폴더의 현재 앱을 다시 추가하세요.

기존 로컬 실기기 검증 범위는 Apple silicon의 macOS 빌드 `25F84`, `25G83`입니다. 확대된 대상은 기기에서 실행되는 입력 검사를 사용하며, 모든 Intel·Apple silicon 모델과 트랙패드 세대를 실기기로 검증했다는 뜻은 아닙니다. 기기별 지원 기능은 [호환성 안내](https://github.com/zamk-DAV/trackpad#지원-범위)를 참고하세요.

[릴리스 자동 검사](https://github.com/zamk-DAV/trackpad/actions/workflows/compatibility.yml)는 macOS 14 Apple silicon, macOS 15·26 Apple silicon/Intel에서 배포 파일을 확인합니다. 실제 제스처·트랙패드 세대·권한·Bluetooth 연결을 검증하는 검사는 아닙니다.

## English

### Changes

- Expanded compatibility targets to macOS 14, 15, and 26, with Intel and Apple silicon executables in one universal app.
- Added external Apple Magic Trackpad discovery with contact and click input matched to the same device. Eligible external devices take priority, with one active trackpad at a time. Pressure gestures are unavailable without Force Touch.
- New compatibility environments and external trackpads check input by having you briefly place two fingers, then lift all fingers. Connected actions remain inactive during validation.
- Added **Fast / Default / Relaxed** keyboard timing presets and **As recorded / A little extra / More extra time** recorded-gesture presets. Detailed timing controls remain available.
- Added the current version and **Check for Updates** in settings. GitHub releases are queried only when you press the button; updates are not installed automatically.
- Added **Preview Diagnostics → Copy Diagnostics** for a limited set of technical details. Rules, input history, and personal file paths are excluded. Nothing is sent automatically.
- Updated the Korean and English installation, usage, and privacy guides.

### Installation and compatibility

1. Download and unzip the archive.
2. Quit Flicklane and move the new `Flicklane.app` to Applications.
3. Open the app and complete permission prompts and the input check.

Existing rules and recorded gestures retain their storage location. If a permission is allowed but not detected, remove the old Flicklane entry in System Settings and add the current app from Applications again.

Existing local hardware validation covers Apple silicon on macOS builds `25F84` and `25G83`. Expanded targets use on-device input checks. This does not certify every Intel or Apple silicon model or trackpad generation. See the [compatibility table](https://github.com/zamk-DAV/trackpad/blob/main/README.en.md#compatibility).

[Automated release checks](https://github.com/zamk-DAV/trackpad/actions/workflows/compatibility.yml) inspect artifacts on macOS 14 Apple silicon and macOS 15/26 Apple silicon and Intel. They do not validate gestures, trackpad generations, permissions, or Bluetooth connections.
