# Flicklane 0.1.3 Beta 1 · build 22

## 한국어

- 캡처 또는 확인창에서 동작을 취소하면 같은 실행의 후속 동작도 멈춥니다. 예를 들어 캡처를 취소한 뒤 이전 클립보드 내용이 붙여넣어지는 것을 방지합니다. 이미 실행한 동작은 되돌리지 않습니다.
- 긴 텍스트를 입력할 때 이모지와 확장 한자가 입력 이벤트 경계에서 잘리는 문제를 수정했습니다.
- 문의용 진단 정보에 화면 기록 권한 상태를 추가했습니다. 개인 입력이나 클립보드 내용은 포함하지 않습니다.
- 창 배치 자동 테스트가 실제 마우스 버튼·보안 입력 상태에 영향을 받지 않도록 개선했습니다. 앱의 입력 보호 조건은 유지됩니다.
- 이번 공개 버전에는 퀵 메뉴(4·5·8·9개 배치)와 퀵 메뉴·화면 분할의 Fn / 🌐 실행 키 지원도 포함됩니다.

## English

- Cancelling a capture or action confirmation now stops subsequent actions in the same execution. For example, cancelling a capture no longer proceeds to paste older clipboard contents. Completed actions are not undone.
- Fixed text input splitting emoji and supplementary Unicode characters between input events.
- Added Screen Recording permission status to support diagnostics, without including personal input or clipboard contents.
- Made window-layout regression tests independent of live mouse-button and Secure Input state while retaining the app's input safeguards.
- This public release also includes Quick Menu with 4/5/8/9 positions and Fn / 🌐 activation for Quick Menu and window tiling.

## Verification / 검증

- 1,076 XCTest tests passed on Apple silicon; the same 1,076 passed as x86_64 under Rosetta.
- Developer ID signature, Apple notarization, stapled ticket, Gatekeeper, and ZIP round-trip checks passed.
- Release workflow: 31 offline scenarios passed; Gatekeeper executable path corrected.
- Five localization catalogs: 1,287 matching keys and interpolation arguments.
- Universal app: arm64 + x86_64. Target macOS versions remain 14, 15, and 26.
- Rosetta and hosted artifact checks do not establish physical Intel, every trackpad model, Bluetooth, or every OS build compatibility.
- 설정 저장 위치와 앱 식별자는 유지됩니다. 기존 앱을 종료한 뒤 새 앱으로 교체하세요. / Quit the previous app before replacing it. Settings storage and app identity are unchanged.
