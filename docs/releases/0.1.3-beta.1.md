## 한국어

이번 버전에는 **커서 옆 퀵 메뉴와 Fn / 🌐 실행 키**가 포함됩니다. 캡처 취소 후 이어지는 동작과 긴 텍스트 입력도 수정했습니다.

### 새로 사용할 수 있는 기능

- **퀵 메뉴:** 상단 네 번째 탭에서 4·5·8·9분할을 고르고 위치별 동작과 표시 이름을 정합니다. 배치를 바꿔도 숨겨진 위치의 설정은 유지됩니다.
- **두 가지 실행 방식:** 전용 키를 누른 채 커서를 움직였다가 키를 놓아 선택하거나, 트랙패드·키보드 규칙에 **퀵 메뉴 열기**를 연결하고 항목을 클릭합니다.
- **선택과 취소:** 5·9분할의 가운데는 지정한 동작을 실행하고, 4·8분할의 가운데는 취소합니다. Esc나 다른 앱으로 이동해도 취소합니다. **메뉴 미리보기**는 실제 동작을 실행하지 않습니다.
- **Fn / 🌐:** 퀵 메뉴와 화면 분할의 실행 키로 선택할 수 있습니다. 같은 키를 쓰면 화면 분할이 우선하므로 서로 다르게 지정하세요. macOS의 Fn 동작은 별도 설정이며, [사용법](../usage.md#fn과-실행-키-충돌)에 설명했습니다.

### 수정한 문제

- 캡처 또는 동작 확인창에서 취소하면 같은 실행의 나머지 동작도 멈춥니다. 취소한 캡처 뒤에 이전 클립보드 내용을 붙여넣던 문제를 방지합니다. 오류 후 계속하기 설정보다 명시적 취소가 우선하며, 이미 완료한 동작은 되돌리지 않습니다.
- 긴 텍스트를 입력할 때 이모지와 확장 한자가 입력 이벤트 경계에서 잘리는 문제를 수정했습니다.
- 진단 정보에 **화면 기록 권한 상태**를 추가했습니다. 규칙·키 입력 기록·클립보드 내용은 포함하지 않으며 자동으로 전송하지 않습니다.
- 창 배치 자동 테스트가 실제 마우스 버튼·보안 입력 상태에 영향을 받지 않도록 개선했습니다. 앱의 입력 보호 조건은 유지합니다.
- 배포 스크립트의 Gatekeeper 도구 경로를 수정했습니다.

### 업데이트

기존 앱을 **⏻ 종료**한 뒤 ZIP의 `Flicklane.app`으로 응용 프로그램 폴더의 앱을 교체하세요. 설정에서 **0.1.3 (22)**를 확인할 수 있습니다. 규칙·녹화·퀵 메뉴·화면 분할·언어 설정을 계속 사용합니다.

## English

This release includes **Quick Menu beside the cursor and Fn / 🌐 activation**, along with fixes for actions following a cancelled capture and long text input.

### Available in this release

- **Quick Menu:** Use the fourth feature tab to choose 4, 5, 8, or 9 positions and assign titles and actions. Switching layouts preserves hidden positions.
- **Two ways to select:** Hold a dedicated key, move the pointer, and release; or add **Open Quick Menu** to a trackpad/keyboard rule and click an item.
- **Selection and cancellation:** The center runs its assigned action in 5/9 layouts and cancels in 4/8 layouts. Escape or switching apps also cancels. **Preview menu** does not execute actions.
- **Fn / 🌐:** Available for Quick Menu and Window Layout. Window Layout takes priority if both use the same key, so choose different keys. macOS has a separate Fn preference; see the [guide](../usage.en.md#fn-and-activation-key-conflicts).

### Fixes

- Cancelling a capture or action confirmation stops remaining actions in that execution. A cancelled capture no longer proceeds to paste older clipboard content. Explicit cancellation takes precedence over the continue-after-error setting. Completed actions are not undone.
- Fixed emoji and supplementary Unicode characters being split between input events in long text.
- Added **Screen Recording permission status** to diagnostics. Rules, key input history, and clipboard contents are excluded; nothing is sent automatically.
- Made window-layout tests independent of live mouse-button and Secure Input state while retaining the app's input safeguards.
- Corrected the Gatekeeper executable path in release tooling.

### Updating

Use **⏻ Quit**, then replace the app in Applications with `Flicklane.app` from the ZIP. Settings should show **0.1.3 (22)**. Existing rules, recordings, Quick Menu, Window Layout, and language preferences are retained.
