# Flicklane 0.1.4 Beta 1

**빌드 / build 23 · Universal: Apple silicon + Intel · macOS 14 / 15 / 26**

[**다운로드 / Download (.zip)**](https://github.com/zamk-DAV/trackpad/releases/download/v0.1.4-beta.1/Flicklane-0.1.4-23-universal.zip)

## 한국어

**키보드 매크로에 저장한 동작을 퀵 메뉴에서도 실행할 수 있습니다.** 매크로를 시작하는 키와 앱에 보낼 키를 따로 설정하는 흐름도 개선했습니다.

### 새로운 기능과 개선

- **저장된 매크로 연결:** 퀵 메뉴의 위치를 선택하고 **연결 대상**에서 키보드 매크로를 고릅니다. 원본의 활성화된 동작을 순서대로 실행하며 오류 발생 시 중단/계속 설정을 따릅니다. 원본 이름과 동작 변경도 반영합니다.
- **키·단축키 누르기:** 실행 동작에서 **누를 키 직접 지정**을 눌러 단일 키나 키 조합을 지정합니다. 예: `V`, `[`, `]`, `⌘C`, `⌘⇧S`. 실행 입력과 보낼 키가 각각 표시됩니다.
- **문구 타이핑:** `Shift+A → youtube.com`처럼 문구를 현재 입력 위치에 타이핑합니다. 웹사이트를 여는 동작과 구분됩니다. 필요한 경우 Enter 등 다른 키 동작을 뒤에 추가하세요.
- **입력 안정성:** 문구 출력에 키 누름·뗌 이벤트를 함께 보내고 보조 키 상태를 초기화합니다. 앱이 만든 입력은 매크로 인식을 다시 시작하지 않도록 표시합니다.
- **연결 상태 확인:** 삭제·비활성화된 규칙, 사용할 수 없는 프리셋, 앱 범위가 맞지 않는 규칙은 실행하지 않습니다. 퀵 메뉴를 다시 여는 규칙의 중첩 실행도 막습니다.
- **다섯 언어:** 새 설정과 안내를 한국어·영어·일본어·중국어 간체/번체로 제공합니다.

### 사용과 업데이트

먼저 매크로 탭에서 키 출력이나 문구 타이핑 동작을 저장하고 규칙과 프리셋을 켜세요. **퀵 메뉴 → 위치 선택 → 연결 대상**에서 해당 규칙을 고르면 같은 동작을 메뉴에서도 실행할 수 있습니다. 앱별 범위는 메뉴를 열었던 앱을 기준으로 확인합니다.

기존 앱을 **⏻ 종료**한 뒤 ZIP의 `Flicklane.app`으로 응용 프로그램 폴더의 앱을 교체하세요. 설정에서 **0.1.4 (23)**를 확인합니다. 기존 규칙·녹화·퀵 메뉴·화면 분할·언어 설정은 유지됩니다. 퀵 메뉴 연결은 앱 환경설정, 매크로 동작은 규칙 파일에 각각 저장되므로 규칙 JSON 하나가 전체 설정 백업은 아닙니다.

## English

**Run the actions saved in Keyboard Macros from Quick Menu as well.** This release also separates the keys that trigger a macro from the keys it sends to your app.

### Features and improvements

- **Link saved macros:** Select a Quick Menu position and choose a keyboard macro under **Linked action**. It runs the original rule's enabled actions in order and follows its stop/continue-on-error setting. Changes to the original name and actions are reflected in the menu.
- **Press keys or shortcuts:** Use **Record output keys** to assign a single key or a combination, such as `V`, `[`, `]`, `⌘C`, or `⌘⇧S`. The trigger and output keys are shown separately.
- **Type text:** Configure, for example, `Shift+A → youtube.com` to type at the current insertion point. This is separate from opening a website. Add an Enter key action afterward if needed.
- **Input reliability:** Text output pairs key-down and key-up events and clears inherited modifier flags. Generated input is marked so that it does not retrigger macro recognition.
- **Link validation:** Deleted or disabled rules, unavailable presets, and app-scope mismatches do not execute. Rules that reopen Quick Menu cannot run recursively from a slot.
- **Five languages:** New controls and guidance are available in Korean, English, Japanese, Simplified Chinese, and Traditional Chinese.

### Using and updating

Save key-output or text-typing actions in Keyboard Macros, then enable the rule and its preset. Select the rule in **Quick Menu → a position → Linked action** to run the same actions from the menu. App scope is checked against the app where the menu opened.

Use **⏻ Quit**, then replace the app in Applications with `Flicklane.app` from the ZIP. Settings should show **0.1.4 (23)**. Existing rules, recordings, Quick Menu, Window Layout, and language settings are retained. Menu links are stored in app preferences and macro actions in the rules file; the rules JSON alone is not a complete settings backup.

macOS 14·15·26의 내장 트랙패드와 확인 가능한 외장 Apple Magic Trackpad를 호환 대상으로 합니다. 자동 검사는 모든 Mac·트랙패드 세대의 실기기 동작, Bluetooth, 권한 처리, 잠자기 복귀를 보증하지 않습니다. 키 출력은 대상 앱의 단축키 설정과 포커스에 따라 달라지며 Photoshop 등 모든 앱에서 실사용을 검증한 것은 아닙니다.

Compatibility targets are built-in trackpads and verifiable external Apple Magic Trackpads on macOS 14, 15, and 26. Automated checks do not establish physical behavior on every model, Bluetooth, permission handling, or wake/reconnect behavior. Key output depends on the target app's shortcuts and focus; real use in every app, including Photoshop, has not been verified.
