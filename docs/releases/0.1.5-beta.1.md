## 한국어

**원형 화면 분할 메뉴를 새롭게 정리하고, 마우스 감도와 스크롤 설정을 추가했습니다.** 새 기능도 한국어·영어·일본어·중국어 간체/번체로 사용할 수 있습니다.

### 새로운 기능과 개선

- **원형 화면 분할 메뉴:** 큰 배치 아이콘, 선택 강조와 체크 표시, 가운데 동작·복원 안내를 제공합니다. 설정 미리보기와 실제 메뉴는 같은 디자인을 사용합니다. 동작 이름을 숨길 수 있고 macOS의 밝은/어두운 모드를 따릅니다.
- **9개 위치 직접 구성:** 절반·가운데 절반·사분면·1/3·2/3·4열·6분할·최대화·거의 최대화·높이 최대화·가운데/모서리 이동·크게/작게·복원을 연결하거나 위치를 비웁니다.
- **같은 배치를 다시 실행하면 복원:** 왼쪽 절반 등 같은 배치를 같은 창에 다시 적용하면 이전 위치와 크기로 돌아갑니다. 크게·작게는 반복해서 조절하며 별도 복원 동작을 사용합니다.
- **마우스와 트랙패드 스크롤 분리:** 종류별로 macOS 따르기·자연스럽게·일반 방향을 선택합니다. **외부 장치 연결 시 스크롤 자동 반전**은 확인된 외장 기기에만 적용하고 내장 트랙패드는 자체 설정을 유지합니다.
- **포인터 속도와 가속:** 포인터 조절을 켜서 속도·가속을 조정하거나 가속을 끕니다. 설정 해제·초기화·정상 종료 시 변경한 기존 값을 복원하며, 중단된 복원은 다음 실행에서 재시도합니다. 드라이버에 따라 일부 옵션이 제한됩니다.
- **상단 탐색 정리:** 제스처 → 키보드 매크로 → 화면 분할 → 퀵 메뉴 → 마우스 감도 조절 순서로 기능을 엽니다.
- **직접 해보는 사용 방법:** 제스처·키보드·화면 분할·퀵 메뉴를 예시 화면에서 눌러보며 익힙니다. 연습은 실제 규칙이나 다른 앱의 창을 바꾸지 않습니다.

## English

**A redesigned circular Window Layout menu, plus mouse sensitivity and scroll controls.** New features support Korean, English, Japanese, Simplified Chinese, and Traditional Chinese.

### Features and improvements

- **Circular Window Layout menu:** Larger icons, a selection highlight and checkmark, and central action/restore hints. The settings preview matches the live menu. Hide action names and follow macOS light/dark appearance.
- **Configure nine positions:** Assign halves, a centered half, quarters, thirds/two-thirds, four columns, six cells, maximize/almost maximize/maximize height, center/edge/corner movement, larger/smaller, restore, or leave a position empty.
- **Repeat a placement to restore:** Apply the same placement to the same window again to return to its earlier position and size. Larger/Smaller remain incremental; use Restore for those actions.
- **Separate scrolling profiles:** Choose Follow macOS, Natural, or Standard for mice and trackpads. **Automatically reverse scrolling for external devices** applies only to identified external devices; the built-in trackpad keeps its own setting.
- **Pointer speed and acceleration:** Enable customization to change speed and acceleration or disable acceleration. Turning it off, resetting, or quitting normally restores changed values; interrupted restoration is retried at the next launch. Some options depend on the driver.
- **Main navigation:** Gesture → Keyboard Macros → Window Layout → Quick Menu → Mouse Sensitivity.
- **Hands-on guides:** Practice gestures, keyboard input, window layouts, and Quick Menu inside example screens without modifying real rules or another app's windows.

### Using and updating

Select a position in **Window Layout → circular preview** to change its layout. **Mouse Sensitivity** is a separate top-level tab; new scroll/pointer overrides are off by default. Profiles apply by device type.

Use **⏻ Quit**, then replace the app in Applications with `Flicklane.app` from the ZIP. Settings should show **0.1.5 (24)**. Existing rules, recordings, menu settings, and language selection are retained. Finish recording/testing and reopen the app after changing language.
