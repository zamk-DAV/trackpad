# Flicklane 0.1.0 Beta 1

## 한국어

**Flicklane의 첫 공개 베타입니다.** 아래 Assets에서 `Flicklane-0.1.0-19-arm64.zip`과 `SHA256SUMS`를 받으세요. Developer ID 서명, Apple 공증, 공증 티켓과 Gatekeeper 검증을 완료했습니다.

Flicklane은 Mac의 트랙패드 제스처와 키보드 입력을 원하는 동작에 연결하는 앱입니다.

- 나만의 트랙패드 제스처를 녹화하고 터치 간격·동작 길이의 시간 여유를 조절합니다.
- 키보드 순서 입력은 최대 간격을 0.01~5초로 설정할 수 있습니다. 키 조합도 지원합니다.
- 키와 마우스로 창을 절반·사분면·최대화 위치에 배치합니다.
- 여러 동작을 연결하고 앱별로 적용할 규칙을 정합니다.
- 한국어, 영어, 일본어, 중국어 간체·번체와 시스템 언어 자동 선택을 지원합니다.
- 상단 메뉴 막대에서 ♥ 후원, ⚙ 설정, ⏻ 종료를 사용합니다. 설정은 메인 창을 엽니다.

앱 버전은 **0.1.0, 빌드 19**입니다. Apple silicon Mac의 **내장 트랙패드**를 대상으로 하며, 접촉 입력은 macOS 빌드 **25F84, 25G83**에서만 활성화됩니다. Intel Mac과 외장 Magic Trackpad는 지원하지 않습니다. **다른 Mac 모델에서의 동작 검증은 진행 중**인 초기 베타입니다.

이전 개발용 빌드에서 업데이트하면 macOS가 입력 모니터링·손쉬운 사용 권한을 다시 요구할 수 있습니다. 규칙과 녹화 설정은 그대로 보존됩니다.

검증: 자동 테스트 980개, 배포 절차 테스트 19개, 5개 언어 리소스 검사를 통과했습니다. 최종 ZIP을 압축 해제한 앱도 서명·공증·Gatekeeper 검사를 통과했습니다. 이 검증은 모든 Mac에서 실제 손동작을 확인했다는 뜻은 아닙니다.

## English

**This is the first public beta of Flicklane.** Download `Flicklane-0.1.0-19-arm64.zip` and `SHA256SUMS` from Assets below. Developer ID signing, Apple notarization, ticket validation, and Gatekeeper checks have passed.

Flicklane connects your Mac’s trackpad gestures and keyboard input to the actions you choose.

- Record custom trackpad gestures and adjust timing tolerance between touches and for movement duration.
- Set the maximum interval for keyboard sequences from 0.01 to 5 seconds, or use a key combination.
- Arrange windows in halves, quarters, or the full desktop area with a key and pointer movement.
- Chain actions and configure rules for specific apps.
- Choose Korean, English, Japanese, Simplified Chinese, Traditional Chinese, or the system language.
- Access ♥ Support, ⚙ Settings, and ⏻ Quit from the menu bar. Settings opens the main app window.

The app version is **0.1.0, build 19**. It targets the **built-in trackpad on Apple silicon Macs**. Contact input is enabled only on macOS builds **25F84 and 25G83**. Intel Macs and external Magic Trackpads are not supported. This is an early beta; **validation on other Mac models is still in progress**.

Updating from a development build may require granting Input Monitoring and Accessibility permission again. Your rules and recorded gestures are preserved.

Validation: 980 automated tests, 19 release-workflow tests, and resource checks for all five languages passed. The app extracted from the final ZIP also passed signature, notarization-ticket, and Gatekeeper checks. These checks do not establish physical-gesture behavior on every Mac.
