# Flicklane 0.1.0 Beta 1

## 한국어

**배포 준비 중인 초안입니다. 아직 다운로드할 수 있는 설치 파일은 없습니다.** Developer ID 서명, Apple 공증 및 다른 Mac에서의 설치 확인을 마친 뒤 앱과 SHA-256 체크섬을 추가합니다.

Flicklane은 Mac의 트랙패드 제스처와 키보드 입력을 원하는 동작에 연결하는 앱입니다.

- 나만의 트랙패드 제스처를 녹화하고 터치 간격·동작 길이의 시간 여유를 조절합니다.
- 키보드 순서 입력은 최대 간격을 0.01~5초로 설정할 수 있습니다. 키 조합도 지원합니다.
- 키와 마우스로 창을 절반·사분면·최대화 위치에 배치합니다.
- 여러 동작을 연결하고 앱별로 적용할 규칙을 정합니다.
- 한국어, 영어, 일본어, 중국어 간체·번체와 시스템 언어 자동 선택을 지원합니다.
- 상단 메뉴 막대에서 ♥ 후원, ⚙ 설정, ⏻ 종료를 사용합니다. 설정은 메인 창을 엽니다.

준비 중인 앱 버전은 **0.1.0, 빌드 19**입니다. Apple silicon Mac의 **내장 트랙패드**를 대상으로 하며, 접촉 입력은 macOS 빌드 **25F84, 25G83**에서만 활성화됩니다. Intel Mac과 외장 Magic Trackpad는 지원하지 않습니다. 허용 빌드의 모든 Mac 모델에서 검증된 것은 아닙니다.

## English

**This is a release preparation draft. No installer is available yet.** The app and SHA-256 checksum will be added after Developer ID signing, Apple notarization, and installation checks on another Mac.

Flicklane connects your Mac’s trackpad gestures and keyboard input to the actions you choose.

- Record custom trackpad gestures and adjust timing tolerance between touches and for movement duration.
- Set the maximum interval for keyboard sequences from 0.01 to 5 seconds, or use a key combination.
- Arrange windows in halves, quarters, or the full desktop area with a key and pointer movement.
- Chain actions and configure rules for specific apps.
- Choose Korean, English, Japanese, Simplified Chinese, Traditional Chinese, or the system language.
- Access ♥ Support, ⚙ Settings, and ⏻ Quit from the menu bar. Settings opens the main app window.

The prepared app version is **0.1.0, build 19**. It targets the **built-in trackpad on Apple silicon Macs**. Contact input is enabled only on macOS builds **25F84 and 25G83**. Intel Macs and external Magic Trackpads are not supported. Not every Mac model on those builds has been tested.
