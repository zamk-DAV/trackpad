## 한국어

이번 업데이트는 화면 캡처 권한과 대기·취소 처리를 개선합니다. 기존 규칙과 녹화 제스처는 그대로 유지됩니다.

- **화면 기록 권한:** 앱에서 현재 허용 상태를 확인하고 해당 시스템 설정으로 바로 이동할 수 있습니다. 권한이 없거나 캡처 도중 해제되면 구체적인 안내를 표시합니다. 오래된 권한 항목을 복구하는 방법도 추가했습니다.
- **충분한 캡처 시간:** 영역·창 선택과 시스템 캡처 도구의 30초 제한을 제거했습니다. 화면 녹화도 사용자가 끝낼 때까지 기다립니다. 즉시 실행하는 전체 화면 캡처의 오류 방지 제한은 유지합니다.
- **정확한 취소 표시:** 영역·창 캡처에서 Esc를 누르면 실행 완료가 아닌 취소로 표시됩니다. Control 키로 파일 캡처를 클립보드로 전환하는 동작도 지원합니다.
- **권한 유지 보호:** 개발용 설치 도구가 배포 앱을 다른 서명의 앱으로 덮어써 macOS 권한 연결을 깨뜨리지 않도록 설치 전에 서명 호환성을 확인합니다.

## English

This update improves screen capture permissions, waiting, and cancellation. Existing rules and recorded gestures are preserved.

- **Screen Recording permission:** Check the current grant and open the relevant System Settings pane from the app. Missing or revoked access produces actionable guidance. Recovery instructions cover outdated macOS permission entries.
- **More time to capture:** Removed the 30-second limit from region/window selection and the system capture toolbar. Screen recording can continue until you finish. Immediate full-screen captures retain their failure timeout.
- **Accurate cancellation:** Esc during region/window capture is reported as cancellation. Holding Control to redirect a file capture to the clipboard is supported.
- **Preserve permission identity:** Development installation tools check signing compatibility before replacing a release app, preventing a different signing identity from breaking its macOS permission association.
