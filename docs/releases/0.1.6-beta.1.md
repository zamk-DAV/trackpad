## 한국어

**독·수신기 장치 감지를 수정하고 포인터 설정의 적용 상태를 명확하게 표시합니다.** 새 안내는 한국어·영어·일본어·중국어 간체·번체를 지원합니다.

- **연결 장치 감지:** 앱 실행 후 독이나 USB 수신기로 연결한 마우스가 장치 목록에서 누락되던 문제를 수정했습니다. 주기적 감지와 ‘장치 새로고침’에 최신 목록을 사용합니다. 목록을 읽지 못했을 때 이전 목록을 새 결과로 처리하지 않습니다.
- **적용 확인과 복원:** 변경 요청이 받아들여져도 실제 값이 바뀌지 않으면 적용 성공으로 처리하지 않습니다. 적용 중 실패하면 이전 값으로 복원을 시도하며, 이전 버전에서 남은 복원 기록도 처리합니다.
- **트랙패드 제한 표시:** 기기별 포인터 설정을 확인할 수 없으면 ‘적용 안 됨’ 안내와 비활성화된 조절기를 표시합니다. ‘macOS 포인터 설정 열기’로 시스템의 이동 속도를 조절할 수 있습니다.
- **가속 끄기와 속도 배율:** 구형 가속 끄기 방식에서 무시되는 속도 조절기를 비활성화하고 대상 장치를 안내합니다. 속도 조절을 지원하는 선형 모드는 계속 사용할 수 있습니다.

**현재 확인한 내장 Apple 트랙패드는 Flicklane의 직접 감도 조절이 적용되지 않습니다. 이번 업데이트는 해당 기능을 구현한 버전이 아닙니다.** 스크롤 방향 설정과 제스처 인식은 별도 기능이며, 외부 장치 자동 스크롤 반전은 내장 트랙패드에 적용되지 않습니다.

## English

**Fixes dock/receiver device discovery and makes pointer-setting status explicit.** New messages support Korean, English, Japanese, Simplified Chinese, and Traditional Chinese.

- **Connected-device discovery:** Fixed mice connected through a dock or USB receiver after app launch being missed. Periodic discovery and Refresh Devices use a fresh list. A failed refresh no longer presents an old list as new data.
- **Verification and restoration:** An accepted request is not treated as successful if the actual setting did not change. Failed applications attempt to restore prior values, including recovery records from earlier versions.
- **Trackpad limitations:** Devices without verifiable per-device pointer settings show “Not applied” and disabled controls. Open macOS Pointer Settings provides access to the system tracking-speed control.
- **Acceleration-off speed:** Disables speed controls that legacy acceleration-off modes ignore and identifies affected devices. Supported linear modes retain speed adjustment.

**Direct sensitivity control does not apply to the built-in Apple trackpad tested locally. This update does not implement that capability.** Scroll direction and gesture recognition are separate features. Automatic external-device scroll reversal does not affect the built-in trackpad.

### Updating

Use **⏻ Quit**, then replace the app in Applications with `Flicklane.app` from the ZIP. Settings should show **0.1.6 (25)**. Existing rules, recordings, menu/language settings, and device profiles are retained, including profiles for devices that cannot currently apply them.
